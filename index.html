🤔 What is jegrep?

Imagine you're working on a project and you need to find a piece of code that calculates shipping costs. But you don't remember the variable names, the function names, or even which file it's in. With traditional search, you'd type something like "shipCalc" or "cost()" and hope for the best. That's a waste of time.

With jegrep, you just type: "where do I calculate the shipping cost" or "function that handles international shipping" — and it finds the right code for you. It reads the meaning behind your words, not just exact matches.

Powered by the Jev engine, jegrep understands natural language and semantic relationships. It's like having a smart assistant that knows where everything is in your codebase.

✨ Key Features

  • 🔍 Semantic Search: Describe code in your own words. jegrep uses AI-powered understanding to match meaning, not just keywords.
  • 💬 Natural Language Queries: Use full sentences or phrases like "validate email address" or "send notification to admin".
  • 🧠 Jev Engine: Advanced semantic analysis that understands context, synonyms, and even code structure.
  • 🪶 Lightweight & Fast: Search through large codebases in seconds. No indexing required – works on your existing files.
  • 🖥️ Windows Friendly: Built for modern Windows environments. Simple and straight forward to set up.
  • ⚡ No Setup Hassle: Designed to be as intuitive as possible. You'll be searching within minutes.

🛠️ How It Works (Simple Explanation)

Here's a very basic example:

Your search: "find code that checks if user is logged in"

jegrep finds: isAuthenticated(), authCheck(), session.validate(), checkLoginStatus()

In files: login.js, middleware/auth.js, app.js

jegrep doesn't just find literal matches. It understands that "user logged in" relates to concepts like authentication, session, validation, and login status. This is the magic of the Jev semantic engine.
